---
title: 🔐 Secret files
description: Writing and reading files that hold tokens and keys.
---

```ts
import { readSecretFile, writeSecretFile } from "@kud/cli-safe"

writeSecretFile(configPath, JSON.stringify({ token }, null, 2))

const { data, insecureMode } = readSecretFile(configPath)
```

## `writeSecretFile(path, data, { encoding? })`

Creates missing parent directories 0700 (existing ones are left alone), writes to a temporary file opened 0600 with `O_EXCL` in the same directory, fsyncs it, renames it over `path` and sets `path` to 0600. A reader never sees a half-written file, a symbolic link at `path` is replaced rather than followed, and a file that used to be world-readable no longer is. On failure the temporary file is removed and the error rethrown.

## `readSecretFile(path, { encoding?, onInsecureMode? })`

Returns `{ data, mode, insecureMode }`, where `insecureMode` means group or others have any permission. `onInsecureMode` is `"warn"` (default, a process warning with code `INSECURE_FILE_MODE`), `"throw"` (an `InsecureFileModeError`) or `"ignore"`. `encoding` defaults to `"utf8"`; `null` returns a `Buffer`. Modes are not checked on Windows.
